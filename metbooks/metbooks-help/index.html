MetBooks — 使用帮助 / Help

中文

开始使用

首次启动时，设置并牢记 4 位数字的阅读权限管理口令。在“本地用户”中新增读者并设置昵称与自己的口令。导入书籍后，在“权限管理”中为读者开放书籍并配置阅读量，然后从“书库”进入阅读。

导入与整理书籍

在“文件导入”中选择本地 EPUB 或 PDF 文件，并查看处理进度。同原始文件名的书籍不能重复导入；完成导入后可以修改显示书名。本APP不支持在线下载书籍、不支持在线阅读、不支持上传书籍。

阅读与目录

在书库点击书籍，选择读者并输入该读者的口令。阅读页面支持目录选择、翻页与双指缩放。

配置阅读量

每次进入“权限管理”都需要管理口令。选择书籍，为每个用户开启访问，并设置每日新增量、每周新增量与可新增的星期。文字 EPUB 按章节计数，图片 EPUB 与 PDF 按图片计数。额度按日期逐步开放，不记录是否实际阅读；没有新增额度的日期仍可重读已开放内容。新书和恢复的书籍默认不向任何用户开放。

用户与管理口令

修改或删除本地用户需要该用户自己的口令。在“管理”中修改阅读权限管理口令，需要先验证旧管理口令。忘记管理口令时，请先备份书籍到 MetBooks 之外，再使用系统“删除 App”彻底删除并重新安装；“卸载 App”不会重置。重新安装后设置新管理口令、恢复书籍，并重新建立用户和阅读权限。

备份与恢复

在“管理”的“备份书籍”中选择保存位置，等待完成并确认生成的 .metbooksbackup 文件夹保存在 MetBooks 之外。备份只包含导入完成的书籍。恢复时选择完整的备份文件夹，书籍追加到现有书库，同原始文件名的书籍会跳过。用户、口令、阅读权限和个人阅读位置不会备份或恢复。

常见问题

看不到书籍内容时，请确认导入已完成、读者已获准访问且当前有开放内容。导入或删除尚未完成时，请查看“文件导入”的任务进度。切换中文或英文可在“管理”的“界面语言”中进行。本 App 不提供在线书籍下载。

English

Getting started

On first launch, set and remember a four-digit reading permissions passcode. Add readers under Local Readers with a nickname and their own password. After importing books, allow access and configure reading allowances under Permissions, then open a book from Library.

Importing and organizing books

Select a local EPUB or PDF file under File Import and view the import progress. Books with the same original filename cannot be imported again. You can change the displayed book title after import completes. MetBooks does not support online reading or downloading or uploading books.

Reading and contents

Tap a book in Library, choose a reader, and enter that reader’s password. The reader supports contents navigation, page turning, and pinch zoom.

Configuring reading allowances

Entering Permissions always requires the management passcode. Choose a book, enable access for each reader, and set daily and weekly additions and eligible weekdays. Text EPUBs count chapters; image EPUBs and PDFs count images. Access expands by date without tracking whether content was actually read. Previously available content can still be reread on days with no new allowance. New and restored books are closed to all readers by default.

Readers and the management passcode

Editing or deleting a local reader requires that reader’s own password. Changing the reading permissions passcode under Management requires the old passcode. If you forget it, back up books outside MetBooks, use the system Delete App action, and reinstall. Offload App does not reset it. Set a new passcode after reinstalling, restore books, and recreate readers and permissions.

Backup and restore

Choose a location under Management → Back Up Books, wait for completion, and confirm the resulting .metbooksbackup folder is outside MetBooks. Only fully imported books are backed up. To restore, select the complete backup folder. Books are added to the existing library, and books with the same original filename are skipped. Readers, passwords, permissions, and personal reading positions are not backed up or restored.

Troubleshooting

If book content is unavailable, check that import has completed, the reader has access, and content is currently unlocked. For unfinished imports or deletions, check task progress under File Import. Switch between Chinese and English under Management → Interface Language. This app does not download books online.
