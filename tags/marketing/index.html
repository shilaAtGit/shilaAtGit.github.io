因为MetMessage的服务器只负责转发，所以搭建一个自己的MetMessage服务器是非常简单的。 在本页我来告诉大家如何快速又简单的搭建一个专属服务器。 PS：希望以后我有时间可以为大家提供一键搭建的服务，敬请期待。 专属服务器优点说明 MetMessage的安全逻辑一 APP在我自己的手机里安装，安全！服务器只做转发什么都不知道，安全！！ 等一下。我怎么确定服务器什么都不知道呢？ 无需确定！！我选择搭建自己的服务器！，并且使用只有我和朋友知道的地址！ MetMessage的安全逻辑二 我信任我的朋友，我的MetMessage里面的联系人都是我真的认识的人。 面对面互相扫描二维码添加好友的模式强制约束了信任关系。不好意思，网友真的加不了朋友。 所有的信息都存储在我的手机里，和我的好友的手机里，那还有什么好担心的！！ MetMessage的安全逻辑三 删除APP就什么都没有了，很遗憾，也很棒！！（不要忘了我还能删除服务器呢） 下载应用包 你需要先到github上下载应用包，如果你具有一定的java开发能力，也可以下载源码后自己编译。 URL：github地址 找到右边的Releases，下载jar文件。 采购供应商的托管虚拟机 专属服务器最关键的其实是一个可以手机访问的互联网地址，最简单的获取方式是免费申请一个或者购买一个托管虚拟机。 因为是专属的，建议购买最基础的（也就是最便宜的）服务即可。 以购买阿里云为例，说明购买流程： URL：如何购买一个云服务 搭建自己MetMessage Server 一、首先我们要登录到（购买好的）阿里云托管虚拟机，具体操作参考阿里云购买流程。 登录的首页就能看到自己的互联网地址，它是一个xxx.xxx.xxx.xxx格式的IP地址，请记录下来，这是我们在MetMessage APP里面需要填写的专属服务器地址。 下图红框中的就是你的互联网地址。 二、建立远程连接 通过建立远程连接，可以把下载在本地的代码包上传到服务器上。 这里啰嗦的解释一下：我们在和朋友聊天的过程中，消息从我的手机发送到朋友的手机（或者反过来），是通过一个放在互联网上的server进行传递的，这个server就是我们搭建的目标工程。 1、我们在上面的图片中可以看到“全部操作”按钮，点击后，会弹出更多的操作功能，如下图。 2、选择其中的“workbench 远程连接”，即红色下划线的按钮。 3、会弹出“新建连接”的页面，不用修改任何信息，直接点击“登录”，如下图。 4、登录后会进入命令行交互界面，先不要管它，直接点击左侧的文件夹图标，如下图。 5、点击文件夹图标后，展开的是服务器的文件路径，鼠标右键敲击 root，在root下选择一个文件夹，我选择的是workspace，也可以自己新建一个文件夹，也可以直接使用root文件夹，如下图。 右键点击workspace（或者自己新建的文件夹），在弹出的菜单中选择“上传”功能，如下图。 6、点击“上传”后，会弹出本地的文件路径，也就是我的电脑的磁盘路径了。找到之前下载的jar文件，点击“确定”即可完成上传，如下图。 7、这个时候需要使用命令行交互界面了，参考下面的命令完成应用的启动。 （1）查看当前目录的命令：pwd （2）进入应用包所在的路径的命令：cd /root/workspace （3）启动应用的命令：nohup java -jar weMail-0.0.2.jar > app.log 2>&1 & 8、检查应用服务是否启动成功 回到自己的电脑，开启本地的命令行交互界面。输入如下命令验证服务： （1）telnet 39.96.2.187 12345 如果你看到上面图片中的输出，就大功告成了！之后你需要把这个服务的互联网地址配置到你的手机上的MetMessageAPP中。 URL：如何配置到APP
